# 3D-2D-Room-designer
web-based interior design tool that allows users to create room layouts, visualize furniture in **2D and 3D**, and manage design projects.   Users can configure room dimensions, select furniture, place items inside the room, and save their designs.

This project is built with **React + Vite + Three.js (React Three Fiber)**.

---

## ✨ Features

### 🧭 Dashboard
- Create a new room design
- Enter project name before starting
- View **Recent Designs (last 3 saved)**
- View **My Designs (all saved designs)**
- Delete saved designs
- Launch editor from saved designs

### 🧙 Room Setup Wizard
Step-by-step room configuration:

1. Room Type
2. Room Dimensions (live preview with **2D + 3D measurement view**)
3. Room Shape
4. Colors & Materials
5. Lighting Setup
6. Review & Confirm

### 🏠 Room Designer
Interactive design environment:

- Toggle **2D Plan / 3D View**
- Add furniture from the library
- Drag furniture in the room
- Rotate objects
- Delete objects
- Lock rotation
- Change wall colors and floor materials
- Export project JSON
- Save project to dashboard

### 🪑 Furniture System
- Furniture library with categories
- Search furniture
- Item preview modal
- 3D model loading (`.glb`)
- Auto placement inside room

### 🛒 Cart System
- Add room items to cart
- Cart drawer panel
- View added furniture items

### 🖼 Branding
Application branding updated to:

**Roomio**

Logo used across:
- Dashboard
- Wizard
- Designer navbar
